Features

Everything your team needs

From zero to a fully-featured skill repository in minutes. No cloud dependency, no vendor lock-in.

🔍

Browse & Search

Full-text search, tag filtering, multi-sort ranking. Find the right skill for any task in seconds.

📦

Drag & Drop Upload

Drop a folder, auto-zip, auto-extract frontmatter from SKILL.md. Version with release notes.

🔄

Version Management

Multiple versions coexist. Switch freely. Authors can prune old releases.

🔐

User & Auth System

Registration with admin approval. BCrypt + JWT with refresh tokens. Transfer skills between users.

🎨

Dark Mode & i18n

Light/dark themes. Chinese and English locales. Customizable logo, favicon via config.json.

🛠

Admin Dashboard

Approve users, disable accounts, create users. Full control over who accesses your skill hub.

Quick Start

Install in 3 commands

Zero-config SQLite by default. Scale to PostgreSQL when you're ready.

Step 1 — Install
pip install skillhub-selfhost
Step 2 — Create Admin
skillhub-selfhost admin-init
Step 3 — Launch
skillhub-selfhost server-start
